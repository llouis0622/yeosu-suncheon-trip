## 장소 선택

시간표의 **장소 선택**을 누르고 추천 목록에서 선택합니다. 미선택일 때도 체류시간은 확보하되 지도에서는 다음 확정 장소로 바로 연결합니다. 선택·교체·해제하면 지도 화살표와 이동시간이 함께 바뀝니다. 되돌리기와 다시 실행도 지원합니다.

첫날 빵 포장·점심은 40분, 둘째 날 점심은 60분, 저녁은 90분, 마지막 날 빵집·카페는 40분입니다. 마지막 날은 휴게소 식사 30분이 기본입니다. **여수에서 간단히**를 선택하면 지역 식당 30분으로 대체하며 휴게소 시간을 중복 계산하지 않습니다. 휴게소의 정확한 위치는 정하지 않아 지도에 임의의 점을 찍지 않습니다.

추천 카드의 **네이버지도** 버튼으로 바로 이동할 수 있습니다. 장소 이름이나 **안내**를 누르면 주소·운영시간·짧은 참고사항이 카드 아래로 펼쳐지며, 다시 누르면 접힙니다. 지도 핀이나 일정의 장소를 눌러도 추천 창의 해당 카드로 연결합니다.

추천 창은 **전체 / 식당 / 카페 / 관광·숙소**로 나뉩니다. [사용자가 공유한 네이버 목록](https://naver.me/x4l3DYMu)의 식당·카페는 모두 포함하고, 저장한 곳에는 **★ 저장**을 붙였습니다. 확정 관광·숙소 외에 다른 관광지나 호텔은 추가하지 않았습니다. 저장 목록 41곳 중 다른 호텔 3곳과 아이뮤지엄을 제외한 37곳, 기존 추가 추천 31곳을 합쳐 68곳입니다. 지도에는 부산 동네 기준점 2개도 표시합니다.

순천의 추가 식당·카페처럼 이번 고정 일정에 선택 시간이 없는 장소는 참고 후보입니다. 베네치아는 확정 숙소로 변경 버튼이 없습니다. 객실 예약이나 바다 전망 객실 배정은 이 앱에서 확정하지 않습니다.

## 지도와 화면

Leaflet 1.9.4와 OpenStreetMap 기반 **OSM France HOT 지도**로 도로·지명·해안선을 표시합니다. 지역 경계 없이 드래그하고 전국·세계 단위까지 축소할 수 있습니다. 날짜별 동선, 전체 후보 보기, 부산 포함 보기, 순서 재생을 지원합니다. 외부 길찾기는 **네이버지도만** 연결합니다. 앱이 설치된 기기는 Naver URL Scheme으로 자동차/도보 길찾기를 열고, 컴퓨터는 출발지·도착지의 네이버지도 웹 링크를 사용합니다.

연결선과 화살표는 **방문 순서이며 실제 도로 경로가 아닙니다**. 일부 장소는 근사 좌표로 표시하고 카드 안내에 표시합니다. 이동시간은 기존 구간 자료와 거리·주차 여유를 조합한 계획치입니다. 운영시간과 임시휴무, 대기 시간은 방문 전 확인하세요.

컴퓨터·태블릿 가로는 지도/추천/일정 50/25/25 열, 태블릿 세로는 같은 비율의 행입니다. 경계선을 끌거나 방향키로 조절하며 두 번 누르기·Home·새로고침으로 기본 비율로 돌아갑니다. 휴대폰과 작은 창은 상단 지도/추천/일정 탭을 사용합니다.

선택은 브라우저에 자동 저장하고 공유 링크/JSON으로 다른 기기에 옮깁니다. 이전 v4 선택 정보는 호환되는 식당·카페만 가져오고 숙소는 베네치아로 맞춥니다. 예전 자유 편집 일정 데이터는 덮어쓰지 않습니다.

## 지도 제공 범위

공개 비영리 여행 페이지의 보통 사용량을 전제로 [OSM France 이용 조건](https://www.openstreetmap.fr/usage/)을 따릅니다. 저작자 표시는 지도 우측 아래 항상 표시합니다. 배경 타일은 온라인 연결이 필요하며 사전 다운로드·오프라인 저장·대량 수집 기능은 없습니다. 자동 UI 검사에서는 타일 요청을 끄고 실제 배경은 별도 시각 확인합니다.

Leaflet은 `vendor/leaflet/`에 포함하며 BSD 2-Clause 라이선스를 빌드에도 유지합니다. 별도 API 키나 외부 JavaScript 로딩은 필요 없습니다. 네이버는 외부 지도/길찾기 링크이며 배경 지도의 제공자가 아닙니다.

## 검사와 배포

Python 3, Node.js가 필요합니다.

```bash
bash deploy.sh --check
```

브라우저 검사용 페이지는 `python3 build.py --qa`로 만듭니다. 공식 미리보기 환경에서 `sites-preview start "$PWD"`를 실행한 뒤 `/qa.html`의 **전체 화면·동작 검사** 버튼을 사용합니다. 기본 빌드는 QA 페이지를 제외합니다. 검사 범위는 [QA.md](QA.md)에 기록합니다.

기존 체크아웃에서 `bash deploy.sh`를 실행하면 빌드·검사·커밋·main/gh-pages 푸시·게시된 버전 확인을 진행합니다. 다른 Mac에서는 최신 코드를 임시 폴더에 복제하는 아래 명령을 사용할 수 있습니다. `llouis0622` 계정의 GitHub CLI 로그인이 필요합니다.

```bash
curl -fsSL https://raw.githubusercontent.com/llouis0622/yeosu-suncheon-trip/main/publish.sh | bash
```

기존 작업을 삭제하거나 강제로 덮어쓰지 않습니다. 변경이 없으면 불필요한 커밋을 만들지 않습니다.
