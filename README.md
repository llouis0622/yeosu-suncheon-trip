# 여수-순천 여행

2026년 11월 28일(토)–30일(월), 부산 출발 2박 3일 여행을 직접 편집하는 웹 플래너입니다. 첫날 여수 관광 후 20시 전후 순천으로 이동하고, 순천에서 같은 객실에 2박한 뒤 월요일 점심 이후 부산으로 돌아오는 흐름입니다.

관광·체험 32곳, 카페 17곳, 맛집·간식 23곳, 순천 숙소 12곳을 담았습니다. 장소별 출처와 운영 안내, 추천 체류시간, 지도 링크를 확인하고 날짜별 일정에 추가할 수 있습니다. 숙소는 욕조 호텔과 스파·감성 숙소를 함께 비교합니다.

## 명령어 한 번으로 기존 사이트 배포

맥미니·맥북 어디서든 터미널에서 아래 한 줄을 실행합니다. ZIP 다운로드나 압축 해제는 필요하지 않습니다.

```bash
curl -fsSL https://raw.githubusercontent.com/llouis0622/yeosu-suncheon-trip/main/publish.sh | bash
```

`publish.sh`는 GitHub 로그인과 계정을 확인하고, 원래 저장소 `llouis0622/yeosu-suncheon-trip`을 임시 작업 폴더에 clone합니다. 이어 빌드·검사 → 변경이 있으면 커밋 → main 푸시 → gh-pages 게시 → 배포 버전 확인 → Mac 브라우저 열기를 실행합니다. 같은 소스를 다시 실행하면 불필요한 커밋을 만들지 않습니다.

기존 프로젝트 폴더가 없어도 동작하며, 앞서 실패한 폴더의 미커밋 변경은 건드리지 않습니다. 새 저장소를 만들지 않고 기존 주소 `https://llouis0622.github.io/yeosu-suncheon-trip/`를 갱신합니다. 명령은 GitHub에 올라온 최신 소스를 사용하므로 특정 컴퓨터에만 남아 있는 수정은 포함하지 않습니다.

Git, GitHub CLI, Node.js, Python 3가 필요합니다. Homebrew가 있으면 없는 도구를 설치하고, GitHub 로그인 시 터미널과 브라우저에서 `llouis0622` 계정으로 진행합니다. 이미 인증되어 있으면 다시 로그인하지 않습니다.

기존 로컬 프로젝트에서 직접 소스를 수정했다면 그 폴더에서 아래를 실행합니다.

```bash
bash deploy.sh
```

배포 스크립트는 추가 `git-subtree` 설치나 전역 Git 작성자 설정 없이 실행합니다. 현재 gh-pages 커밋을 부모로 이어서 게시하고 강제 푸시는 하지 않습니다. 출력되는 ‘게시된 버전 확인 완료’는 원격 커밋과 실제 HTML의 빌드 번호를 함께 확인한 결과입니다.

검사만 실행하려면 `bash deploy.sh --check`, 브라우저 자동 열기를 생략하려면 `TRIP_NO_OPEN=1 bash deploy.sh`를 사용합니다.

각 브라우저에 자동 저장한 여행 일정은 Git 소스와 별개이며 JSON 내보내기·가져오기로 기기 간 이동합니다.

## 10분 단위 시간표 편집

- **블록 가운데를 끌기:** 시작 시간을 옮기며 체류시간을 유지합니다. 다른 방문을 넘어가면 방문 순서와 지도 연결 방향도 바뀝니다.
- **주변 일정의 실시간 정렬:** 블록을 끄는 동안 앞뒤 일정과 구간 이동이 함께 자리를 옮깁니다. 옮길 위치는 점선, 손에 든 일정은 떠 있는 카드로 표시하며 놓을 때 미리보기 그대로 부드럽게 정렬됩니다. 비워진 자리는 앞당겨 채우고 길어진 일정 뒤는 밀어냅니다. 영향을 받는 방문의 희망 시작 시각은 자동 계산으로 바뀌며, 체류시간·수동 이동 소요시간·다른 날짜·버스/기차의 목표 출발 시각은 유지합니다. 실제로 늦어지면 기존 경고로 알려줍니다.
- **양 끝을 끌기:** 세로 시간표의 위/아래 끝, 가로 시간표의 왼쪽/오른쪽 끝으로 시작/종료 시간을 바꿉니다. 터치 화면에서는 블록을 먼저 선택하면 양쪽 손잡이가 보입니다. 최소 길이는 10분입니다.
- **10분 칸에 맞추기:** 드래그, 양 끝 조절, 장소 추가의 시작 시간은 가장 가까운 10분에 맞춥니다. 추천 체류시간이 10분 배수가 아니면 10분 단위로 내림합니다. 방문 도착은 다음 10분 칸으로 맞추고 그 차이를 여유시간으로 표시합니다.
- **원하는 시간에 추가:** 세로 시간표 오른쪽의 `＋` 줄에서 원하는 시각을 누른 뒤 장소를 고르세요. 가로 시간표에서는 아래의 `＋ 10시` 줄을 사용합니다. `＋ 장소`의 시작 시간 입력도 사용할 수 있습니다.
- **이동·숙소:** 이동 블록도 이동·길이 변경이 가능합니다. 숙박은 저녁 시작점과 다음 날 아침 종료점을 조절합니다. 승차 준비·지연 여유·체크아웃은 연결 일정으로 자동 계산됩니다.
- **여행 동선 반영:** 앞 일정과 필요한 이동시간을 확보할 수 없는 시각은 가능한 시각으로 조정하며, 끄는 동안 미리보기에 표시합니다. 버스·기차를 놓치거나 영업시간을 넘기면 경고합니다.
- **터치·키보드:** 빈 시간 눈금 쪽을 밀면 시간표가 위아래로 스크롤됩니다. 가로 시간표는 좌우 스크롤입니다. 블록을 가장자리로 끌면 자동 스크롤됩니다. 선택한 블록/손잡이의 방향키는 10분, Shift+방향키는 1시간입니다. Escape로 드래그를 취소하면 움직이던 주변 일정도 원래 자리로 돌아갑니다. 기기의 움직임 줄이기 설정에서는 정렬 애니메이션을 생략합니다.
- **저장과 되돌리기:** 손을 놓을 때 한 번 저장하므로 한 번의 되돌리기로 전체 드래그를 취소합니다. 새로고침 후에도 위치와 수동 이동시간이 유지됩니다. 이동 상세에서 `이 구간 이동시간 자동 계산`으로 추정치로 되돌릴 수 있습니다.

기존 버스·기차의 참고 소요시간(147·25·158분)과 자동 계산한 구간 이동은 실제 근거값을 유지합니다. 이 블록을 직접 끌거나 늘릴 때는 10분 칸으로 맞춥니다. 설정 창에는 예매한 실제 시각을 정확히 입력할 수 있습니다.

## 일정 만들기

1. **A 바다·정원 / B 실내·카페 / C 골목·노을 / D 직접 만들기** 중 출발점을 고릅니다. 각 코스의 편집 내용은 별도로 저장됩니다.
2. 날짜를 선택하고 도시·분류·검색으로 장소를 찾습니다. 기본 지도에는 전체 후보가 보이며, 필요할 때 ‘지도도 필터’를 켭니다.
3. 상세에서 추천 체류시간을 확인하고 그대로 추가하거나 시간을 바꿉니다. 일정의 ‘방문 순서’에서 이동·삭제·날짜 변경·10분 단위 조절을 할 수 있습니다.
4. 설정에서 출발 및 귀환 시각, 열차/버스, 혼합 이동·도보·대중교통·택시, 지연 여유, 숙소, 짐 보관을 변경합니다. 이동 블록을 누르면 해당 구간의 추정 근거·길찾기와 시간 수정 기능을 확인할 수 있습니다.
5. 지도에서 동선 방향과 이동 재생을 확인합니다. 휴무·입장마감·늦은 귀환 경고가 생기면 장소나 시간을 조정하세요.

화면 위의 48px 한 줄에 제목과 **전체 / 지도 / 장소 / 일정** 탭을 모았습니다.

- **컴퓨터·태블릿 가로:** 지도, 추천 장소, 일정을 왼쪽부터 **50% / 25% / 25%**로 표시합니다. 일정은 세로 시간표입니다.
- **태블릿 세로:** 지도, 추천 장소, 일정을 위에서부터 **50% / 25% / 25%**로 표시합니다. 추천은 가로 카드 목록, 일정은 가로 시간표로 바뀝니다.
- **휴대폰·아주 작은 창:** 지도부터 보여 주며 상단 **지도 / 장소 / 일정** 탭으로 전환합니다. 가로로 돌린 휴대폰도 같은 방식입니다.
- **영역 크기 조절:** 지도–추천, 추천–일정 사이의 손잡이를 끌어 두 영역을 넓히거나 줄입니다. 세로로 쌓인 화면에서는 위아래로 끕니다. 다른 한 영역의 크기는 유지됩니다.
- **기본 크기 복원:** 경계선을 두 번 누르면 **50:25:25**로 돌아옵니다. 경계선에 키보드 초점을 두고 방향키로 5%, Shift+방향키로 1%씩 조절하거나 Home으로 초기화할 수 있습니다.
- **비율 기억:** 가로와 세로 화면의 비율을 각각 현재 브라우저에 저장합니다. 회전·새로고침 후 복원하며, 창이 작아지면 각 영역의 최소 크기를 확보하도록 보정합니다. 여행 일정 데이터는 바뀌지 않습니다.

‘지도’·‘장소’·‘일정’ 탭은 해당 영역을 크게 보여 주며, ‘전체’로 돌아오면 조절했던 분할 화면이 복원됩니다. 일정의 ‘방문 순서’에서도 편집할 수 있고, 설정·저장·가져오기는 일정 오른쪽 위 `···` 메뉴에 있습니다.

## 공유와 저장

- 편집은 현재 브라우저에 자동 저장됩니다. 기기 간 실시간 공동 편집·자동 동기화 기능은 없습니다.
- ‘저장·가져오기’에서 **JSON**을 저장해 다른 기기에서 가져오거나, 일정이 포함된 **HTML** 파일을 전달할 수 있습니다.
- Pages 배포 후 ‘현재 일정 공유 링크’를 복사하면 상대가 같은 일정에서 시작합니다. 이후의 변경은 새 링크를 보내야 합니다. 긴 일정은 JSON 파일 공유를 권합니다.
- `yeosu-suncheon.html`은 별도 서버나 API 키 없이 여는 단일 파일 버전입니다. `dist/index.html`과 내용이 같습니다.

## 여행일 기준으로 확인할 사항

**11월 30일은 마지막 월요일이라 순천만국가정원과 순천만습지가 모두 정기 휴무입니다.** 추천안은 두 장소를 일요일에 배치하며, 월요일에 추가하면 경고합니다. [공식 운영 안내](https://scbay.suncheon.go.kr/garden/0016/0001/0001/)

귀환 기본 계산은 **사상터미널 17:38 도착**입니다. 집까지 18시 도착이 필요하면 더 이른 편을 선택하세요. 기차·버스 예매 후 설정의 시각과 소요시간을 실제 표에 맞춰 바꿔주세요. [부산서부터미널 여수 노선](https://www.busantr.com/sub04/01.htm?wr_id=372) · [코레일](https://www.korail.com/) · [고속버스](https://www.kobus.co.kr/) · [시외버스](https://txbus.t-money.co.kr/)

교통은 구간에 따라 기존 지도 조회값 또는 거리·우회·대기시간을 반영한 추정값입니다. 각각 구분해서 표시하며 지도 선은 도로 경로가 아닌 이동 방향을 보여줍니다. 혼합 이동의 초기값은 짧은 구간 도보, 중간 거리 대중교통, 긴 구간 택시이며 구간마다 변경할 수 있습니다.

가격과 영업시간은 2026-10-25 조사 기준입니다. 미래 영업·빈방·예약가는 보장하지 않으며 장소별 원문에서 확인하세요. 숙소 2박 예산 30만원은 사용자가 편집하는 계획 금액입니다. 욕조·스파는 지정 객실과 추가요금 조건을 확인해야 합니다. 일부 입장료가 미확정인 시설은 총액에서 빠질 수 있습니다. 정원·습지 통합입장권은 같은 날 중복 계산하지 않습니다.
