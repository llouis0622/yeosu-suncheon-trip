## 사용 방법

시간표의 **장소 선택**을 누르고 추천 목록에서 식당·카페를 선택합니다. 미선택 식사와 휴식도 체류시간은 확보하지만 지도에서는 건너뜁니다. 선택하면 그 장소를 거치는 이동 화살표로 바뀝니다. 순서와 체류시간은 고정이며, 이동·개장 대기에 따라 도착 시각을 다시 계산합니다. 선택 해제·되돌리기·다시 실행도 가능합니다.

숙소는 **신라스테이 여수**가 기본값입니다. 추천 목록에서 숙소를 바꾸면 여수 2박과 세 날짜의 숙소 이동이 함께 바뀝니다. 카페와 고소동 벽화마을은 같은 3일차 시간대의 대안으로 한 곳만 선택합니다.

추천 목록에는 관광지 8곳, 고정 찹쌀떡 방문지 및 식당·카페 47곳, 여수 숙소 8곳이 있습니다. 지도에는 부산 동네 기준점 2개를 포함한 총 65개 점을 표시합니다. 목록을 필터링해도 지도 후보는 유지됩니다. 순천 카페처럼 확정 일정에 선택 시간이 없는 장소는 참고 후보로만 남습니다.

컴퓨터·태블릿 가로 화면은 지도/추천/일정 열을 50/25/25로, 태블릿 세로 화면은 같은 비율의 행으로 보여줍니다. 경계선을 끌거나 방향키로 크기를 조절합니다. 두 번 누르기·Home·새로고침으로 기본 비율로 돌아갑니다. 휴대폰과 작은 창은 제목 옆 지도/추천/일정 탭을 사용합니다.

선택은 브라우저에 자동 저장됩니다. 다른 기기는 공유 링크나 JSON으로 옮깁니다. 예전 자유 편집 일정의 저장 데이터는 덮어쓰지 않습니다.

## 계산과 자료의 범위

- 자차 이동은 과거 경로 자료, 도시 간 계획치, 좌표 거리·주차 여유를 조합한 **추정**입니다. 지도 화살표는 이동 방향이며 도로 경로가 아닙니다. 구간 버튼에서 실제 길찾기를 열 수 있습니다.
- 시간은 10분 단위로 계획합니다. 관람시간을 줄여 마감에 맞추지 않으며 늦어지는 경우 확인 메시지를 표시합니다.
- 장소 정보·공식 링크는 각 상세 화면에 있습니다. 신규 장소 위치 일부는 근사 좌표로 명시되어 있습니다. 운영시간과 주말 대기, 11월 28~30일 실제 객실 가격·재고는 예약 직전 확인해야 합니다.
- 아르떼뮤지엄은 안내된 18시 마감·17시 입장마감을 반영합니다. 해오름전시실의 점심 휴게시간과 두 전시관의 월요일 휴무를 반영합니다.
- 공개 페이지에는 정확한 집 주소 대신 대연동·당감동 기준점만 사용합니다.

## 검사 및 빌드

필요 도구: Python 3, Node.js. 외부 JavaScript 라이브러리나 API 키는 필요하지 않습니다.

```bash
bash deploy.sh --check
```

실제 브라우저 회귀 검사는 다음과 같이 준비합니다. 앱과 `qa.html`을 같은 정적 서버에서 열어 **전체 화면·동작 검사**를 실행합니다. 배포용 기본 빌드에서는 QA 페이지를 제외합니다.

```bash
python3 build.py --qa
# 이 환경: sites-preview start "$PWD"
# 표시된 미리보기 주소의 /qa.html 열기
```

`engine.js`: 일정·이동 계산 / `ui.js`, `ui.css`: 선택 UI·반응형 화면 / `map.js`, `map.css`, `map-fragment.html`: 기존 지도·화살표·재생 / `data.json`: 장소·고정 일정 / `build.py`: 외부 의존성 없는 `dist/index.html` 생성.

## 기존 GitHub 저장소에 배포

현재 체크아웃에서:

```bash
bash deploy.sh
```

다른 Mac에서는 파일을 직접 옮기지 않고 아래 명령을 실행할 수 있습니다. 최신 main을 임시 폴더에 복제하고, 검사·소스 커밋·main 및 gh-pages 푸시·실제 게시 버전 확인을 진행합니다. llouis0622 계정으로 GitHub CLI 로그인이 필요합니다.

```bash
curl -fsSL https://raw.githubusercontent.com/llouis0622/yeosu-suncheon-trip/main/publish.sh | bash
```

기존 작업 폴더를 삭제하거나 강제로 덮어쓰지 않습니다. 새로 배포할 코드 변경이 없다면 불필요한 커밋을 만들지 않습니다.
