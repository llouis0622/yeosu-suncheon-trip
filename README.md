# 여수-순천 여행

2026년 11월 28일(토)–30일(월), 부산 출발 2박 3일 여행을 직접 편집하는 웹 플래너입니다. 첫날 여수 관광 후 20시 전후 순천으로 이동하고, 순천에서 같은 객실에 2박한 뒤 월요일 점심 이후 부산으로 돌아오는 흐름입니다.

관광·체험 32곳, 카페 17곳, 맛집·간식 23곳, 순천 숙소 12곳을 담았습니다. 장소별 출처와 운영 안내, 추천 체류시간, 지도 링크를 확인하고 날짜별 일정에 추가할 수 있습니다. 숙소는 욕조 호텔과 스파·감성 숙소를 함께 비교합니다.

## 새 저장소 생성 및 GitHub Pages 배포

Mac에 Git, Python 3, Node.js, GitHub CLI가 필요합니다. Homebrew를 사용한다면 없는 도구만 설치하세요.

```bash
brew install gh node python
```

압축을 푼 `YeosuSuncheonTrip` 폴더에서 실행합니다.

```bash
bash deploy.sh
```

이 명령은 검사를 실행한 뒤 **llouis0622/yeosu-suncheon-trip** 공개 저장소를 새로 만들고 `main`에 소스를, `gh-pages`에 사이트를 게시합니다. 필요한 경우 GitHub 로그인을 안내합니다. 완료 후 배포된 버전을 확인하고 접속 주소를 출력합니다.

예상 주소: **https://llouis0622.github.io/yeosu-suncheon-trip/** — 실제 배포 전에는 열리지 않습니다.

같은 이름의 저장소가 이미 있고 이 폴더와 연결되지 않았다면 중단합니다. 새 이름을 지정할 수 있습니다.

```bash
bash deploy.sh yeosu-suncheon-trip-2
```

첫 배포 후에는 **같은 폴더에서** `bash deploy.sh`를 다시 실행하면 수정본을 게시합니다. 별도 이름으로 만들었다면 업데이트할 때도 같은 이름을 전달하세요. 기존 `november-travel` 저장소는 사용하지 않습니다. 강제 푸시를 하지 않으므로 원격 변경과 충돌하면 중단합니다.

게시하지 않고 검사만 실행하려면:

```bash
bash deploy.sh --check
```

## 일정 만들기

1. **A 바다·정원 / B 실내·카페 / C 골목·노을 / D 직접 만들기** 중 출발점을 고릅니다. 각 코스의 편집 내용은 별도로 저장됩니다.
2. 날짜를 선택하고 도시·분류·검색으로 장소를 찾습니다. 기본 지도에는 전체 후보가 보이며, 필요할 때 ‘지도도 필터’를 켭니다.
3. 상세에서 추천 체류시간을 확인하고 그대로 추가하거나 시간을 바꿉니다. 일정의 ‘방문 순서’에서 이동·삭제·날짜 변경·15분 단위 조절을 할 수 있습니다.
4. 설정에서 출발 및 귀환 시각, 열차/버스, 혼합 이동·도보·대중교통·택시, 지연 여유, 숙소, 짐 보관을 변경합니다. 이동 블록을 누르면 해당 구간의 추정 근거·길찾기와 시간 수정 기능을 확인할 수 있습니다.
5. 지도에서 동선 방향과 이동 재생을 확인합니다. 휴무·입장마감·늦은 귀환 경고가 생기면 장소나 시간을 조정하세요.

900px 이하 화면에서는 **지도 / 장소 / 일정** 탭을 사용합니다. 큰 화면에서는 지도와 장소를 나란히, 일정은 아래에서 봅니다. 일정 확대와 되돌리기·다시 실행도 지원합니다.

## 공유와 저장

- 편집은 현재 브라우저에 자동 저장됩니다. 기기 간 실시간 공동 편집·자동 동기화 기능은 없습니다.
- ‘저장·가져오기’에서 **JSON**을 저장해 다른 기기에서 가져오거나, 일정이 포함된 **HTML** 파일을 전달할 수 있습니다.
- Pages 배포 후 ‘현재 일정 공유 링크’를 복사하면 상대가 같은 일정에서 시작합니다. 이후의 변경은 새 링크를 보내야 합니다. 긴 일정은 JSON 파일 공유를 권합니다.
- `yeosu-suncheon.html`은 별도 서버나 API 키 없이 여는 단일 파일 버전입니다. `dist/index.html`과 내용이 같습니다.

## 여행일 기준으로 확인할 사항

**11월 30일은 마지막 월요일이라 순천만국가정원과 순천만습지가 모두 정기 휴무입니다.** 추천안은 두 장소를 일요일에 배치하며, 월요일에 추가하면 경고합니다. [공식 운영 안내](https://scbay.suncheon.go.kr/garden/0016/0001/0001/)

교통편은 여행일 확정 예매 시간표가 아닌 수정 가능한 참고값입니다.

| 구간 | 기본 계획값 | 계산에 더한 여유 |
| --- | --- | --- |
| 부산 사상 → 여수터미널 | 07:30 출발, 147분 | 승차 준비 20분, 도착 지연 30분 |
| 여수EXPO역 → 순천역 | 20:00 목표 출발, 25분 | 승차 준비 20분, 도착 지연 10분 |
| 순천터미널 → 부산 사상 | 14:30 출발, 158분 | 승차 준비 20분, 도착 지연 30분 |

귀환 기본 계산은 **사상터미널 17:38 도착**입니다. 집까지 18시 도착이 필요하면 더 이른 편을 선택하세요. 기차·버스 예매 후 설정의 시각과 소요시간을 실제 표에 맞춰 바꿔주세요. [부산서부터미널 여수 노선](https://www.busantr.com/sub04/01.htm?wr_id=372) · [코레일](https://www.korail.com/) · [고속버스](https://www.kobus.co.kr/) · [시외버스](https://txbus.t-money.co.kr/)

교통은 구간에 따라 기존 지도 조회값 또는 거리·우회·대기시간을 반영한 추정값입니다. 각각 구분해서 표시하며 지도 선은 도로 경로가 아닌 이동 방향을 보여줍니다. 혼합 이동의 초기값은 짧은 구간 도보, 중간 거리 대중교통, 긴 구간 택시이며 구간마다 변경할 수 있습니다.

가격과 영업시간은 2026-10-25 조사 기준입니다. 미래 영업·빈방·예약가는 보장하지 않으며 장소별 원문에서 확인하세요. 숙소 2박 예산 30만원은 사용자가 편집하는 계획 금액입니다. 욕조·스파는 지정 객실과 추가요금 조건을 확인해야 합니다. 일부 입장료가 미확정인 시설은 총액에서 빠질 수 있습니다. 정원·습지 통합입장권은 같은 날 중복 계산하지 않습니다.

## 파일과 개발

| 파일 | 역할 |
| --- | --- |
| `data.json` | 장소 84곳, 교통 거점 4곳, 출처·운영 안내·추천 코스·기존 이동 조회값 |
| `engine.js` | 일정·이동·휴무·예산 계산 |
| `ui.js`, `ui.css` | 지도·필터·편집·재생과 반응형 화면 |
| `map-fragment.html` | 기존 SVG 지도 |
| `build.py` | 단일 HTML 및 `dist` 생성 |
| `deploy.sh` | 검사·새 저장소 생성·Pages 게시·배포 버전 확인 |

```bash
python3 build.py
python3 -m http.server 8080 --directory dist
```

이후 `http://localhost:8080`에서 열 수 있습니다. 외부 패키지 설치나 API 키 없이 동작합니다.

## 검증 범위

일정 계산·휴무·편집·날짜 이동·지도 제스처 상태·재생·반응형 상태 전환과 빌드 검사가 포함됩니다. DOM fixture 검사는 실제 화면 배치 검증이 아닙니다. 제작 환경의 로컬 서버·브라우저 접근 제한으로 실제 렌더링과 기기 터치 검증은 수행하지 못했습니다. 배포 후 모바일과 PC에서 지도 이동·확대, 장소 검색·추가, 순서 변경, 저장·공유와 가로 회전을 확인하세요.
